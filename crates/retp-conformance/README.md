# retp-conformance

Checks an ETP v1.2 server against what the specification makes mandatory, and writes the report a provider can act on: one check, one cited rule, one verdict.

- Separate from the client: a server is judged by the specification, not by what the client happens to accept.
- The `retp-conformance` binary writes Markdown and JSON reports.
